# v3 (PentaBuzzer / ESP32-S3) Hardware Support Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Teach BlueBuzzah-Updater to detect, download the correct firmware asset for, and flash BlueBuzzah v3 hardware (PentaBuzzer, Seeed XIAO ESP32-S3) alongside existing v2 (nRF52840) support.

**Architecture:** Firmware releases now ship two assets per release (nRF Nordic-DFU zip + v3 esptool-image zip with `manifest.json`). The frontend gains a `BoardType` dimension threaded through asset selection, caching, device detection, and deployment. The Rust backend gains a board-keyed cache, ESP32-S3 device detection, and a new `esp` flasher module built on the `espflash` crate that reuses the existing `DfuStage` progress pipeline and post-flash role-config flow.

**Tech Stack:** React 18 + TypeScript + Vitest (frontend), Rust + Tauri 2.0 (backend), `espflash` 4.5 (ESP32-S3 flashing), existing `serialport`/`zip`/`sha2` crates.

## Global Constraints

- Asset name patterns (verbatim from objectives): nRF = `/^BlueBuzzah-Firmware-(?!v3-)/`, v3 = `/^BlueBuzzah-Firmware-v3-/`.
- Format detection if ever needed: top-level `manifest` key = Nordic, `manifest_version` key = v3. Keep the Nordic and v3 read paths entirely separate.
- v3 device USB ID: VID `0x303A` (Espressif), PID `0x1001` (USB-JTAG/Serial). Same VID/PID in app mode and ROM download mode — `in_bootloader` is always `false` for v3.
- v3 manifest (produced by `BlueBuzzah-Firmware/scripts/package_penta.py`): `manifest_version: 1`, `board: "pentabuzzer_esp32s3"` (the PIO env name), `chip: "esp32s3"`, `flash: {mode, freq, size}` (e.g. `dio`/`80m`/`8MB`), `application_version`, `parts: [{path, offset (hex string e.g. "0x0"), sha256}]`. Four parts: `bootloader.bin` (0x0), `partitions.bin` (0x8000), `boot_app0.bin` (0xE000), `firmware.bin` (0x10000).
- **Validate `board`/`chip` before flashing** and verify each part's SHA256 after reading it from the archive. Flash each part at its manifest offset — never hardcode offsets or flash params in the updater.
- v3 firmware speaks the same post-flash serial command set (`SET_ROLE:...`, `[CONFIG]`/`[ERROR]` markers) — reuse the existing role-config flow.
- Rollout order: updater release with Tasks 1–4 (Objectives 1–2) → first dual-asset firmware release (dry-run prerelease tag first) → updater release with Tasks 5–10 (Objectives 3–5).
- Display naming: any device matching `0x303A:0x1001` is labeled **"BlueBuzzah v3"**; the nRF52840 hardware is labeled **"BlueBuzzah v2"** (port appended, e.g. `BlueBuzzah v3 (/dev/cu.usbmodem101)`).
- **Batch flashing is single-board only:** when two devices are flashed in one wizard run they must be the same hardware version. The UI prevents mixed selection; the install flow also guards defensively.
- App-only fast path (flash `firmware.bin` alone) is **deferred** — out of scope for this plan.
- Repo conventions: strict TypeScript (no `any`), shadcn/ui + Tailwind only, colocated `*.test.ts(x)` tests, Rust `#[cfg(test)]` at file bottom, no AI attribution in commits.
- Commands: frontend tests `npm test`, typecheck+build `npm run build`, Rust tests `cd src-tauri && cargo test`, Rust check `cd src-tauri && cargo check`.
- All paths below are relative to the `BlueBuzzah-Updater` repo root.

```ts
export const V3_ASSET_PATTERN = /^BlueBuzzah-Firmware-v3-/;

export function getAssetForBoard(
  release: FirmwareRelease,
  board: BoardType

  const pattern = board === 'esp32s3' ? V3_ASSET_PATTERN : NRF_ASSET_PATTERN;
  return (
    release.assets.find((a) => pattern.test(a.name) && a.name.endsWith('.zip')) ??

  );
}
```

```rust
pub fn find_supported_devices() -> Vec<Nrf52Device> {
    let mut devices = Vec::new();
    let ports = match available_ports() {
        Ok(ports) => ports,
        Err(_) => return devices,
    };

    for port in ports {
        #[cfg(target_os = "macos")]
        if port.port_name.contains("/dev/tty.") {
            continue;
        }

        if let SerialPortType::UsbPort(usb_info) = &port.port_type {
            let (board, in_bootloader) =
                if is_compatible_device(usb_info.vid, usb_info.pid) {
                    ("nrf52", is_bootloader_pid(usb_info.pid))
                } else if is_esp32s3_device(usb_info.vid, usb_info.pid) {
                    // USB-JTAG/Serial: same VID/PID in app and download mode.
                    ("esp32s3", false)
                } else {
                    continue;
                };

            devices.push(Nrf52Device {
                port: port.port_name.clone(),
                vid: usb_info.vid,
                pid: usb_info.pid,
                serial_number: usb_info.serial_number.clone(),
                in_bootloader,
                product_name: usb_info.product.clone(),
                manufacturer: usb_info.manufacturer.clone(),
                board: board.to_string(),
            });
        }
    }
    devices
}
```

```rust
pub(crate) fn parse_offset(s: &str) -> Result<u32, String> {
    let s = s.trim();
    let parsed = if let Some(hex) = s.strip_prefix("0x").or_else(|| s.strip_prefix("0X")) {
        u32::from_str_radix(hex, 16)

        s.parse::<u32>()

}

/// Read, validate, and load a v3 firmware package.
pub fn read_v3_zip<P: AsRef<Path>>(path: P) -> Result<V3Package, String> {
    let file = std::fs::File::open(path.as_ref())
        .map_err(|e| format!("Failed to open firmware package: {}", e))?;
    let mut archive =
        zip::ZipArchive::new(file).map_err(|e| format!("Invalid firmware zip: {}", e))?;

    let mut manifest_json = String::new();
    archive
        .by_name("manifest.json")
        .map_err(|_| "manifest.json not found in firmware package".to_string())?
        .read_to_string(&mut manifest_json)
        .map_err(|e| format!("Failed to read manifest.json: {}", e))?;

    // Format guard: v3 manifests are flat with `manifest_version`;
    // Nordic manifests have a top-level `manifest` key.
    let raw: serde_json::Value = serde_json::from_str(&manifest_json)
        .map_err(|e| format!("manifest.json is not valid JSON: {}", e))?;
    if raw.get("manifest_version").is_none() {
        return Err("This is not a v3 firmware package (no manifest_version)".to_string());
    }

    let manifest: V3Manifest = serde_json::from_value(raw)
        .map_err(|e| format!("Invalid v3 manifest: {}", e))?;

    if manifest.manifest_version != EXPECTED_MANIFEST_VERSION {
        return Err(format!(
            "Unsupported v3 manifest version {} (updater supports {})",
            manifest.manifest_version, EXPECTED_MANIFEST_VERSION
        ));
    }
    if manifest.chip != EXPECTED_CHIP {
        return Err(format!(
            "Firmware package targets chip '{}', expected '{}'",
            manifest.chip, EXPECTED_CHIP
        ));
    }
    if manifest.board != EXPECTED_BOARD {
        return Err(format!(
            "Firmware package targets board '{}', expected '{}'",
            manifest.board, EXPECTED_BOARD
        ));
    }
    if manifest.parts.is_empty() {
        return Err("v3 manifest lists no flash parts".to_string());
    }

    let mut parts = Vec::with_capacity(manifest.parts.len());
    for meta in &manifest.parts {
        let offset = parse_offset(&meta.offset)?;
        let mut data = Vec::new();
        archive
            .by_name(&meta.path)
            .map_err(|_| format!("Part '{}' missing from firmware package", meta.path))?
            .read_to_end(&mut data)
            .map_err(|e| format!("Failed to read part '{}': {}", meta.path, e))?;

        let actual = sha256_hex(&data);
        if !actual.eq_ignore_ascii_case(&meta.sha256) {
            return Err(format!(
                "SHA256 mismatch for '{}' (package corrupt?)",
                meta.path
            ));
        }
        parts.push(LoadedPart {
            name: meta.path.clone(),
            offset,
            data,
        });
    }
    parts.sort_by_key(|p| p.offset);

    Ok(V3Package { manifest, parts })
}
```

```rust
//! ESP32-S3 flashing via the espflash crate.
//!
//! Mirrors the shape of `dfu::protocol::upload_firmware` and reuses `DfuStage`
//! so the frontend progress pipeline works unchanged.

use std::time::Duration;

use espflash::flasher::{Flasher, ProgressCallbacks};
use espflash::target::Chip;

use crate::dfu::{
    configure_device_role_flexible, find_supported_devices, get_reboot_settle_delay,
    get_reboot_timeout, wait_for_application_flexible, DeviceIdentifier, DfuStage,
};
use super::manifest::read_v3_zip;

/// Bridges espflash per-part progress into cumulative DfuStage::Uploading events.
struct StageProgress<'a> {
    emit: &'a dyn Fn(DfuStage),
    total: usize,
    done_before_part: usize,
    part_len: usize,
}

impl ProgressCallbacks for StageProgress<'_> {
    fn init(&mut self, _addr: u32, len: usize) {
        self.part_len = len;
    }
    fn update(&mut self, current: usize) {
        (self.emit)(DfuStage::Uploading {
            sent: self.done_before_part + current.min(self.part_len),
            total: self.total,
        });
    }
    fn finish(&mut self, _skipped: bool) {
        self.done_before_part += self.part_len;
        (self.emit)(DfuStage::Uploading {
            sent: self.done_before_part,
            total: self.total,
        });
    }
    // Implement any remaining trait methods (e.g. verifying) as no-ops per
    // the espflash 4.5 trait definition.
}

/// Flash a v3 firmware package and configure the device role.
pub fn flash_v3<F, C>(
    port_name: &str,
    zip_path: &str,
    device_role: &str,
    on_progress: F,
    is_cancelled: C,
) -> Result<(), String>
where
    F: Fn(DfuStage),
    C: Fn() -> bool,
{
    // Step 1: read + validate package (board/chip/sha256 checked inside)
    on_progress(DfuStage::ReadingPackage);
    let package = read_v3_zip(zip_path)?;
    let total: usize = package.parts.iter().map(|p| p.data.len()).sum();
    on_progress(DfuStage::Log {
        message: format!(
            "v3 package: {} parts, {} bytes, app {}, flash {}/{}/{}",
            package.parts.len(),
            total,
            package.manifest.application_version,
            package.manifest.flash.mode,
            package.manifest.flash.freq,
            package.manifest.flash.size
        ),
    });

    // Step 2: capture identity for post-flash tracking (port may re-enumerate)
    let device = find_supported_devices()
        .into_iter()
        .find(|d| d.port == port_name)
        .ok_or_else(|| format!("Device not found on port {}", port_name))?;
    if device.board != "esp32s3" {
        return Err(format!(
            "Device on {} is not a v3 (ESP32-S3) device",
            port_name
        ));
    }
    let identifier = DeviceIdentifier::from_device(&device);

    // Step 3: connect (espflash resets the S3 into download mode via
    // USB-JTAG/Serial control lines)
    on_progress(DfuStage::Connecting);
    if is_cancelled() {
        on_progress(DfuStage::Cancelled);
        return Err("Cancelled".to_string());
    }
    let connection = open_connection(port_name)?;
    let mut flasher = Flasher::connect(
        connection,
        true,               // use_stub: faster, enables progress granularity
        false,              // verify: manifest SHA256 already verified from zip
        false,              // skip
        Some(Chip::Esp32s3),
        None,               // keep default baud after connect
    )
    .map_err(|e| format!("Failed to connect to ESP32-S3 bootloader: {}", e))?;

    // Step 4: write each part at its manifest offset
    let mut progress = StageProgress {
        emit: &on_progress,
        total,
        done_before_part: 0,
        part_len: 0,
    };
    for part in &package.parts {
        if is_cancelled() {
            on_progress(DfuStage::Cancelled);
            return Err("Cancelled".to_string());
        }
        on_progress(DfuStage::Log {
            message: format!("Flashing {} at 0x{:X} ({} bytes)", part.name, part.offset, part.data.len()),
        });
        flasher
            .write_bin_to_flash(part.offset, &part.data, &mut progress)
            .map_err(|e| format!("Failed to flash {}: {}", part.name, e))?;
    }

    // Step 5: reset into the application
    on_progress(DfuStage::Finalizing);
    flasher
        .connection()
        .reset()
        .map_err(|e| format!("Failed to reset device after flash: {}", e))?;
    drop(flasher);

    // Step 6: wait for the app and configure role (same flow as nRF post-DFU)
    on_progress(DfuStage::WaitingForReboot);
    std::thread::sleep(Duration::from_millis(get_reboot_settle_delay()));
    let app_device = wait_for_application_flexible(&identifier, get_reboot_timeout())
        .map_err(|e| format!("{}", e))?;

    on_progress(DfuStage::ConfiguringRole);
    configure_device_role_flexible(&app_device.port, device_role, &identifier)
        .map_err(|e| format!("{}", e))?;

    on_progress(DfuStage::Complete);
    Ok(())
}

/// Open the serial port and build an espflash Connection with the
/// USB-JTAG/Serial reset strategy. Confirm exact constructor against
/// docs.rs/espflash 4.5 (connection module) when compiling.
fn open_connection(port_name: &str) -> Result<espflash::connection::Connection, String> {
    let serial = serialport::new(port_name, 115_200)
        .timeout(Duration::from_millis(3000))
        .open_native()
        .map_err(|e| format!("Failed to open {}: {}", port_name, e))?;
    let port_info = find_usb_port_info(port_name)?;
    Ok(espflash::connection::Connection::new(
        serial,
        port_info,
        espflash::connection::reset::ResetAfterOperation::HardReset,
        espflash::connection::reset::ResetBeforeOperation::default(),
        115_200,
    ))
}

fn find_usb_port_info(port_name: &str) -> Result<serialport::UsbPortInfo, String> {
    let ports = serialport::available_ports()
        .map_err(|e| format!("Failed to enumerate ports: {}", e))?;
    ports
        .into_iter()
        .find(|p| p.port_name == port_name)
        .and_then(|p| match p.port_type {
            serialport::SerialPortType::UsbPort(info) => Some(info),
            _ => None,
        })
        .ok_or_else(|| format!("USB info not found for {}", port_name))
}
```

```rust
/// Flash v3 (ESP32-S3) firmware and configure the device role.
///
/// No operation-level retry loop: esptool-style flashing has no USB
/// re-enumeration mid-flash. Role config retries internally.
#[tauri::command]
pub async fn flash_v3_firmware(
    serial_port: String,
    firmware_path: String,
    device_role: String,
    progress: Channel<DfuProgressEvent>,
) -> Result<(), String> {
    if DFU_IN_PROGRESS.swap(true, Ordering::SeqCst) {
        return Err("A firmware update is already in progress".to_string());
    }
    let _guard = DfuGuard;
    DFU_CANCELLED.store(false, Ordering::SeqCst);

    let (tx, rx) = mpsc::channel::<DfuStage>();
    let progress_channel = progress.clone();
    let progress_task = thread::spawn(move || {
        while let Ok(stage) = rx.recv() {
            let event = DfuProgressEvent::from(stage);
            if progress_channel.send(event).is_err() {
                eprintln!("[ESP] Warning: progress channel disconnected, cancelling");
                DFU_CANCELLED.store(true, Ordering::SeqCst);
            }
        }
    });

    let result = tokio::task::spawn_blocking(move || {
        crate::esp::flash_v3(
            &serial_port,
            &firmware_path,
            &device_role,
            move |stage| {
                let _ = tx.send(stage);
            },
            is_dfu_cancelled,
        )
    })
    .await
    .map_err(|e| format!("v3 flash panicked: {}", e))?;

    let _ = progress_task.join();
    result
}
```
